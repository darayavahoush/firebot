1. System Architecture & Dual-Compute Split

The FireBot rover implements an asymmetric compute split between real-time low-level actuation and high-throughput sensory perception:

  • ESP32 Microcontroller (Hard Real-Time): Handles microsecond pulse timing for 4x ultrasonic distance sensors, 20 kHz ultrasonic motor PWM, 12-bit ADC analog conversion (MQ-2 gas sensors, water tank float, battery voltage), logic-level MOSFET switching for the 12V diaphragm water pump, and hardware safety watchdog enforcement (halting all actuators if communication drops for >500ms).
  • Raspberry Pi 4 / 5 (Linux SBC): Interfaces with the 32x24 Far-Infrared thermal camera (MLX90640-D55) over I2C at 400 kHz, runs the client link agent (firebot.link.realhw:RealHardware), and streams 10 Hz telemetry frames over Wi-Fi TCP port 8765 to the PC Brain while executing returned motion and nozzle commands.

2. Electrical Wiring & Power Rails

CRITICAL HARDWARE PROTECTION RULE: DUAL BUCK CONVERTERS Never power the Raspberry Pi and the DC motors/servos from the same 5V regulator. Geared DC motors and diaphragm pumps generate severe inductive kickback and transient voltage sags. Always deploy two separate buck converters: Buck #1 dedicated to ESP32 + sensors + servos, and Buck #2 dedicated to the Raspberry Pi. Both converters must share a common ground bus.

2.1 HC-SR04 Ultrasonic 5V to 3.3V Voltage Divider

HC-SR04 ultrasonic sensors require 5V VCC to emit high-frequency acoustic pings. Consequently, their Echo output is a 5V logic signal. Because ESP32 GPIO pins tolerate only up to 3.3V, every Echo line must pass through a 1 kΩ / 2 kΩ resistor voltage divider before entering the ESP32:

HC-SR04 Echo Pin (5V Logic) | [ 1.0 kΩ Resistor ] | +------------------------> To ESP32 Echo Pin (GPIO 34 / 35 / 36 / 39) [3.3V Safe] | [ 2.0 kΩ Resistor ] | GND (Ground)

2.2 12V Diaphragm Water Pump MOSFET Circuit

The water pump draws 1.5A to 3.0A at 12V DC. An N-channel logic-level MOSFET (IRLZ44N or IRLB8721) switches the pump's negative terminal. A 1N4007 flyback diode across the pump motor terminals clamps inductive back-EMF spikes when switching off. A 10 kΩ pull-down resistor prevents unintended floating gate triggers during ESP32 boot.

+12V Raw Battery Rail | +--------------------+ | | [ 12V Diaphragm ] [ Flyback Diode ] [ Water Pump ] [ 1N4007 ] (Cathode stripe to +12V) | | +--------------------+ | Drain ESP32 GPIO 17 ---------> Gate [ IRLZ44N N-MOSFET ] | Source [ 10 kΩ ] | | v GND GND

2.3 Battery Voltage Monitor Divider (12V Pack)

To safely measure the 12.6V fully-charged 3S LiPo battery using the ESP32 12-bit ADC:
Divider: R1 = 10 kΩ, R2 = 2.2 kΩ. Max voltage at pin = $12.6\text{ V} \times \frac{2.2}{10 + 2.2} = 2.27\text{ V}$ (well within ESP32 3.3V ADC range).

4. Production ESP32 Firmware Source Code

This code must be flashed to the ESP32 using the Arduino IDE or PlatformIO. It is stored in the repository at firmware/esp32/firebot_esp32.ino. 

/*
 * FIREBOT ESP32 EMBEDDED CONTROLLER FIRMWARE
 * Real-time acquisition of 4x Ultrasonic, 3x Flame, 2x MQ-2,
 * Dual DC Motors (TB6612FNG), 12V Water Pump MOSFET, SG90 Turret Servo,
 * and 500ms Hardware Safety Watchdog.
 */
#include <Arduino.h>
#include <ArduinoJson.h>
#include <ESP32Servo.h>

// --- Pin Definitions ---
#define PIN_US_FL_TRIG   13
#define PIN_US_FL_ECHO   34
#define PIN_US_FR_TRIG   12
#define PIN_US_FR_ECHO   35
#define PIN_US_L_TRIG    14
#define PIN_US_L_ECHO    36
#define PIN_US_R_TRIG    27
#define PIN_US_R_ECHO    39

#define PIN_FLAME_L      25
#define PIN_FLAME_C      26
#define PIN_FLAME_R      33

#define PIN_MQ2_FRONT    32
#define PIN_MQ2_REAR     15

#define PIN_TANK_LEVEL    4
#define PIN_BATT_MONITOR  2

#define PIN_MOTOR_L_PWM  18
#define PIN_MOTOR_L_IN1  19
#define PIN_MOTOR_L_IN2  21
#define PIN_MOTOR_R_PWM  22
#define PIN_MOTOR_R_IN3  23
#define PIN_MOTOR_R_IN4   5

#define PIN_PUMP_GATE    17
#define PIN_SERVO_PAN    16

#define PWM_FREQ         20000
#define PWM_RES          8
#define SERIAL_BAUD      115200
#define TELEMETRY_RATE_HZ 10
#define WATCHDOG_MS      500

Servo servoPan;
unsigned long lastTelemetryTime = 0;
unsigned long lastCommandTime = 0;
bool failsafeTriggered = false;

float cmd_v = 0.0f, cmd_w = 0.0f;
bool  cmd_pump = false;
float cmd_turret = 0.0f;

float pose_x = 0.0f, pose_y = 0.0f, pose_theta = 0.0f, measured_speed = 0.0f;
unsigned long lastOdomTime = 0;
const float MAX_LINEAR_SPEED = 0.60f;
const float MAX_ANGULAR_SPEED = 2.50f;

void haltActuators() {
  digitalWrite(PIN_MOTOR_L_IN1, LOW);
  digitalWrite(PIN_MOTOR_L_IN2, LOW);
  ledcWrite(PIN_MOTOR_L_PWM, 0);

  digitalWrite(PIN_MOTOR_R_IN3, LOW);
  digitalWrite(PIN_MOTOR_R_IN4, LOW);
  ledcWrite(PIN_MOTOR_R_PWM, 0);

  digitalWrite(PIN_PUMP_GATE, LOW);
  cmd_v = 0.0f; cmd_w = 0.0f; cmd_pump = false; measured_speed = 0.0f;
}

void applyMotorCommands(float v, float w) {
  float u_l = constrain(v - (w * 0.5f), -1.0f, 1.0f);
  float u_r = constrain(v + (w * 0.5f), -1.0f, 1.0f);

  digitalWrite(PIN_MOTOR_L_IN1, u_l > 0.02f ? HIGH : LOW);
  digitalWrite(PIN_MOTOR_L_IN2, u_l < -0.02f ? HIGH : LOW);
  ledcWrite(PIN_MOTOR_L_PWM, (uint32_t)(fabs(u_l) * 255.0f));

  digitalWrite(PIN_MOTOR_R_IN3, u_r > 0.02f ? HIGH : LOW);
  digitalWrite(PIN_MOTOR_R_IN4, u_r < -0.02f ? HIGH : LOW);
  ledcWrite(PIN_MOTOR_R_PWM, (uint32_t)(fabs(u_r) * 255.0f));

  measured_speed = v * MAX_LINEAR_SPEED;
}

float readUltrasonicMeters(uint8_t trigPin, uint8_t echoPin) {
  digitalWrite(trigPin, LOW); delayMicroseconds(2);
  digitalWrite(trigPin, HIGH); delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  unsigned long duration = pulseIn(echoPin, HIGH, 24000);
  if (duration == 0) return 4.0f;
  return constrain((duration * 0.0343f / 2.0f) / 100.0f, 0.03f, 4.0f);
}

void sendTelemetryFrame() {
  StaticJsonDocument<512> doc;
  doc["t"] = millis() / 1000.0f;
  JsonArray poseArr = doc.createNestedArray("pose");
  poseArr.add(round(pose_x * 1000.0f) / 1000.0f);
  poseArr.add(round(pose_y * 1000.0f) / 1000.0f);
  poseArr.add(round(pose_theta * 1000.0f) / 1000.0f);

  doc["speed"] = round(measured_speed * 100.0f) / 100.0f;
  doc["tank"]  = round((analogRead(PIN_TANK_LEVEL) / 4095.0f) * 100.0f) / 100.0f;
  doc["turret"] = round(cmd_turret * 100.0f) / 100.0f;

  JsonObject s = doc.createNestedObject("sensors");
  s["us_front_left"]  = round(readUltrasonicMeters(PIN_US_FL_TRIG, PIN_US_FL_ECHO) * 100.0f) / 100.0f;
  s["us_front_right"] = round(readUltrasonicMeters(PIN_US_FR_TRIG, PIN_US_FR_ECHO) * 100.0f) / 100.0f;
  s["us_left"]        = round(readUltrasonicMeters(PIN_US_L_TRIG, PIN_US_L_ECHO) * 100.0f) / 100.0f;
  s["us_right"]       = round(readUltrasonicMeters(PIN_US_R_TRIG, PIN_US_R_ECHO) * 100.0f) / 100.0f;
  s["flame_left"]     = (digitalRead(PIN_FLAME_L) == LOW) ? 1.0f : 0.0f;
  s["flame_center"]   = (digitalRead(PIN_FLAME_C) == LOW) ? 1.0f : 0.0f;
  s["flame_right"]    = (digitalRead(PIN_FLAME_R) == LOW) ? 1.0f : 0.0f;
  s["mq2_front"]      = round((analogRead(PIN_MQ2_FRONT) / 4095.0f) * 1000.0f) / 1000.0f;
  s["mq2_rear"]       = round((analogRead(PIN_MQ2_REAR) / 4095.0f) * 1000.0f) / 1000.0f;

  serializeJson(doc, Serial);
  Serial.println();
}

void processIncomingCommands() {
  while (Serial.available() > 0) {
    String line = Serial.readStringUntil('\n');
    line.trim();
    if (line.length() == 0) continue;

    StaticJsonDocument<256> doc;
    if (!deserializeJson(doc, line)) {
      if (doc.containsKey("v") && doc.containsKey("w") && doc.containsKey("pump")) {
        cmd_v = doc["v"].as<float>();
        cmd_w = doc["w"].as<float>();
        cmd_pump = doc["pump"].as<bool>();
        if (doc.containsKey("turret")) cmd_turret = doc["turret"].as<float>();
        lastCommandTime = millis();
        failsafeTriggered = false;

        applyMotorCommands(cmd_v, cmd_w);
        digitalWrite(PIN_PUMP_GATE, cmd_pump ? HIGH : LOW);
        servoPan.write((int)constrain(90.0f + (cmd_turret * 90.0f), 0.0f, 180.0f));
      }
    }
  }
}

void checkWatchdog() {
  if (!failsafeTriggered && (millis() - lastCommandTime > WATCHDOG_MS)) {
    haltActuators();
    failsafeTriggered = true;
  }
}

void setup() {
  Serial.begin(SERIAL_BAUD);
  pinMode(PIN_MOTOR_L_IN1, OUTPUT); pinMode(PIN_MOTOR_L_IN2, OUTPUT);
  pinMode(PIN_MOTOR_R_IN3, OUTPUT); pinMode(PIN_MOTOR_R_IN4, OUTPUT);
  ledcAttach(PIN_MOTOR_L_PWM, PWM_FREQ, PWM_RES);
  ledcAttach(PIN_MOTOR_R_PWM, PWM_FREQ, PWM_RES);
  pinMode(PIN_PUMP_GATE, OUTPUT);
  servoPan.attach(PIN_SERVO_PAN, 500, 2500);

  pinMode(PIN_US_FL_TRIG, OUTPUT); pinMode(PIN_US_FL_ECHO, INPUT);
  pinMode(PIN_US_FR_TRIG, OUTPUT); pinMode(PIN_US_FR_ECHO, INPUT);
  pinMode(PIN_US_L_TRIG, OUTPUT);  pinMode(PIN_US_L_ECHO, INPUT);
  pinMode(PIN_US_R_TRIG, OUTPUT);  pinMode(PIN_US_R_ECHO, INPUT);

  pinMode(PIN_FLAME_L, INPUT); pinMode(PIN_FLAME_C, INPUT); pinMode(PIN_FLAME_R, INPUT);
  analogReadResolution(12);
  analogSetAttenuation(ADC_11db);

  haltActuators();
}

void loop() {
  processIncomingCommands();
  checkWatchdog();
  if (millis() - lastTelemetryTime >= (1000 / TELEMETRY_RATE_HZ)) {
    lastTelemetryTime = millis();
    sendTelemetryFrame();
  }
}

5. Production Raspberry Pi Hardware Driver (`realhw.py`)

This driver executes on the Raspberry Pi under Python 3.10+. It implements the exact Hardware protocol required by firebot.link.agent:PiAgent. Stored at src/firebot/link/realhw.py. 

"""Real robot hardware driver for Raspberry Pi + ESP32."""
from __future__ import annotations
import glob, json, logging, time
from typing import Any
from .protocol import SCALARS, THERM_COLS, THERM_ROWS, Command, Frame

log = logging.getLogger("firebot.realhw")

try:
    import serial
except ImportError:
    serial = None

try:
    import board, busio, adafruit_mlx90640
except ImportError:
    adafruit_mlx90640 = None

def find_serial_port() -> str:
    candidates = (glob.glob("/dev/ttyUSB*") + glob.glob("/dev/ttyACM*") +
                  glob.glob("/dev/serial0") + glob.glob("/dev/cu.usbserial*"))
    return candidates[0] if candidates else "/dev/ttyUSB0"

class RealHardware:
    def __init__(self, port: str = "auto", baud: int = 115200) -> None:
        self.port = find_serial_port() if port == "auto" else port
        self.baud = baud
        self.ser: Any = None
        self.mlx: Any = None
        self._raw_thermal = [25.0] * (THERM_ROWS * THERM_COLS)
        self._last_t = time.monotonic()
        self._pose = (0.0, 0.0, 0.0)
        self._speed = 0.0
        self._tank = 1.0
        self._turret = 0.0
        self._sensors = {s: 0.0 for s in SCALARS}
        self._sensors.update({"us_front_left": 2.0, "us_front_right": 2.0,
                              "us_left": 2.0, "us_right": 2.0})
        self._init_mlx()
        self._init_serial()

    def _init_mlx(self) -> None:
        if adafruit_mlx90640 is None:
            log.warning("adafruit_mlx90640 missing; using simulated thermal grid")
            return
        try:
            i2c = busio.I2C(board.SCL, board.SDA, frequency=400000)
            self.mlx = adafruit_mlx90640.MLX90640(i2c)
            self.mlx.refresh_rate = adafruit_mlx90640.RefreshRate.REFRESH_8_HZ
            log.info("MLX90640 active on I2C address 0x33")
        except Exception as e:
            log.warning("MLX90640 unavailable (%s); fallback to ambient", e)
            self.mlx = None

    def _init_serial(self) -> None:
        if serial is None: return
        try:
            self.ser = serial.Serial(self.port, self.baud, timeout=0.05)
            time.sleep(1.5)
            self.ser.reset_input_buffer()
            log.info("Connected to ESP32 on %s @ %d baud", self.port, self.baud)
        except Exception:
            self.ser = None

    def _read_esp32_telemetry(self) -> None:
        if self.ser is None:
            self._init_serial()
            if self.ser is None: return
        try:
            while self.ser.in_waiting > 0:
                raw = self.ser.readline()
                if not raw: break
                line = raw.decode("utf-8", errors="ignore").strip()
                if not line.startswith("{") or not line.endswith("}"): continue
                msg = json.loads(line)
                if "t" in msg: self._last_t = float(msg["t"])
                if "pose" in msg: self._pose = tuple(float(x) for x in msg["pose"][:3])
                if "speed" in msg: self._speed = float(msg["speed"])
                if "tank" in msg: self._tank = max(0.0, min(1.0, float(msg["tank"])))
                if "turret" in msg: self._turret = float(msg["turret"])
                for k, v in msg.get("sensors", {}).items():
                    if k in self._sensors: self._sensors[k] = float(v)
        except Exception:
            try: self.ser.close()
            except Exception: pass
            self.ser = None

    def _read_thermal_frame(self) -> list[list[float]]:
        if self.mlx is not None:
            try:
                self.mlx.getFrame(self._raw_thermal)
            except Exception: pass
        return [[round(float(self._raw_thermal[r * THERM_COLS + c]), 1)
                 for c in range(THERM_COLS)] for r in range(THERM_ROWS)]

    def read(self) -> Frame:
        self._read_esp32_telemetry()
        return Frame(seq=0, t=self._last_t, pose=self._pose, speed=self._speed,
                     tank=self._tank, sensors=dict(self._sensors),
                     thermal=self._read_thermal_frame(), turret=self._turret)

    def apply(self, cmd: Command) -> None:
        if self.ser is None: return
        try:
            line = json.dumps({"v": round(cmd.v, 3), "w": round(cmd.w, 3),
                               "pump": bool(cmd.pump), "turret": round(cmd.turret, 3),
                               "ack": int(cmd.ack)}, separators=(",", ":")) + "\n"
            self.ser.write(line.encode("ascii"))
            self.ser.flush()
        except Exception:
            try: self.ser.close()
            except Exception: pass
            self.ser = None

    def stop(self) -> None:
        if self.ser is None: return
        try:
            line = json.dumps({"v": 0.0, "w": 0.0, "pump": False,
                               "turret": 0.0, "ack": -1}) + "\n"
            self.ser.write(line.encode("ascii"))
            self.ser.flush()
        except Exception: pass

7. Step-by-Step Setup, Flashing & Verification

  1. Flash the ESP32:
    • Open the Arduino IDE.
    • Install libraries via Library Manager: ArduinoJson (Benoit Blanchon) and ESP32Servo (Kevin Harrington).
    • Set Board: ESP32 Dev Module (CPU: 240MHz, Upload: 921600 or 115200).
    • Plug the ESP32 into your computer via USB and click Upload.
  2. Configure the Raspberry Pi:
    • Enable 400 kHz Fast-Mode I2C in /boot/firmware/config.txt (or /boot/config.txt): 
      dtparam=i2c_arm=on,i2c_arm_baudrate=400000
    • Install python driver dependencies on the Pi: 
      pip install pyserial adafruit-circuitpython-mlx90640
    • Verify the MLX90640 is detected at I2C address 0x33: 
      sudo i2cdetect -y 1
  3. Run Bench Self-Test:
    • With the ESP32 plugged into the Pi USB port, run: 
      python3 -m firebot.link.realhw
    • Verify 10 test frames print to console showing sensor values and central thermal readings.
  4. Start Live Autonomous Mission:
    • Connect to the PC Brain host over the local network: 
      firebot-pi --host <PC_IP_ADDRESS> --token <FIREBOT_TOKEN> --rate 10.0
